# Objetivo
Se quiere integrar en el sistema un sistema que pemita ingresar los gastos y hacer el cierre durante el dia, es decir crear un mantenimiento de gastos mas la opcion de otros par aescribir texto o algo asi, pero por defecto vamos a crear todo, entonces en el app se pueden registrar estos gastos, opciones para que el usuario seleccione.

Luego en el area de gastos el usuario va a poder seleccionar los gastos que se definen en el mantenimiento para despues ingresar el monto del gasto. Esto se grabara por dia un historial de gastos, gastos ingresados para al final obtener el reporte diario.

Actualizar el sistema de reportes, no solo se quiere tener ventas, actualizarlo a gastos, gastos involucrados y poder hacer cierre, imprimir las ventas menos los gastos para que el cleinte pueda comprabar las ventas usando la impresora.
